# TVM for iPhone and iPad

Standalone SwiftUI app. It ships a production build of `apps/ui` and an on-device
Core that serves that UI from a loopback HTTP server (`http://127.0.0.1:7345` by
default). Run `pod install` in `apps/ios`, then open `TVM.xcworkspace` in Xcode on a Mac.

**You do not need a PC, a host address, a LAN token, or Core on another computer.**
The first screen is TVM itself. Real-Debrid, profiles, watchlist, plan (sandbox),
progress and settings persist on the phone (Application Support + Keychain).

A “Use a home Core” control exists only as optional advanced pairing with a
computer on the same Wi-Fi. It is not required to launch or watch.

## What this IPA is

| Claim | Truth |
| --- | --- |
| Standalone phone app | Yes. Bundled UI + local `/api`. |
| App Store / TestFlight signed | **No.** Re-sign with your Apple ID. |
| Needs `TVM_LAN_TOKEN` / PC Core | **No** (optional only). |
| ffmpeg remux / transcode on iOS | **No FFmpeg service.** MobileVLCKit 3.6.0 decodes MP4, MKV, WebM, AVI, MPEG-TS and HLS on the phone. |
| Live TV provider login | Playlist / Xtream credentials can be stored. HLS and raw MPEG-TS use native VLC playback. |
| GitHub login / in-app update | **No.** Install a new IPA. |
| Home Screen icon named TVM | Yes, after Sideloadly/AltStore/Xcode install of a signed build. |

## What works on this Windows workspace

| Step | Status here |
| --- | --- |
| Source project (`TVM.xcodeproj`, Swift, plists, shared scheme, AppIcon) | Present |
| `node apps/ios/check-project.mjs` | Packaging check only (no Swift compile) |
| `node apps/ios/bundle-ui.mjs` | Builds `apps/ui` and copies it into `TVM/BundledUI` (does not compile an IPA) |
| `export-ipa.cmd` / `export-ipa.ps1` | **Always fails.** `xcodebuild` does not run on Windows. |
| `request-ipa.ps1` | Downloads a **real** unsigned CI IPA *if* GitHub Actions `mobile.yml` has already compiled one on a macOS runner |
| Signed or unsigned `.ipa` file in this tree | **Not produced on this PC.** Windows cannot run `xcodebuild`. |
| App Store / TestFlight upload | Not possible from this PC |

This is **not** a signed or App Store IPA. Do not rename a zip of Swift source to `.ipa`.

## On-device API

The WKWebView loads the bundled UI from the loopback server. `apiFetch` uses
relative `/api` on that origin. Implemented locally (Swift):

- health, home, library, media + children, search
- profiles, watchlist, progress
- plan (sandbox checkout), billing (no live card processor), usage
- Real-Debrid status / token (Keychain) / library / Torrentio + unrestrict playback
- apps list + hub catalogs (Cinemeta; mock hubs are not licensed apps)
- live playlist store (HLS and raw MPEG-TS through VLC)
- art proxy (allow-listed image hosts), settings/legal export + erase
- ads preroll skipped, system session (not an appliance), update apply refused

Playback uses unrestricted HTTP(S) sources in a full-screen native MobileVLCKit player. Container support no longer depends on WebKit or a Real-Debrid Apple transcode. The picture fits and centers in portrait and landscape; controls provide 10-second seeking, a scrubber, embedded audio/subtitles, speed, rotation and left-edge Back. Progress returns to the shared UI. Missing, expired, DRM-protected or damaged sources can still fail; supported codecs also depend on the decoder and device.

Browsing fills the actual iPhone/iPad window (only media keeps its aspect ratio), disables pinch zoom and document overscroll, and sends left-edge swipes to TVM’s navigation stack. The launcher icon is generated by `generate-app-icon.mjs`.

## Sideload on an iPhone (after you have a real IPA)

You need a binary that Xcode (or the `mobile.yml` macos job) actually compiled. Then **re-sign** it with *your* Apple ID.

### Sideloadly (Windows)

1. Install [Sideloadly](https://sideloadly.io/) on this PC.
2. Unlock the iPhone, connect USB, tap Trust.
3. Open Sideloadly. Drag `TVM.ipa` or `TVM-unsigned.ipa`.
4. Sign in with your Apple ID. Start the install.
5. On the phone: **Settings → General → VPN & Device Management** → trust that Apple ID.
6. Free Apple IDs expire in **7 days**. Re-sign before then. A paid Apple Developer membership lasts a year.

The TVM icon appears on the Home Screen like any other signed app. An unsigned CI zip will not launch until this step succeeds.

### AltStore

1. Install [AltServer](https://altstore.io/) on Windows or a Mac on the same Wi-Fi.
2. Plug in the iPhone and install AltStore onto it from AltServer.
3. In AltStore on the phone, sideload the IPA (or use AltServer’s “Sideload .ipa…”).
4. Trust the developer cert as above. Refresh the app from AltStore before the 7-day free-ID expiry.

### Xcode on a Mac (most reliable)

```sh
cd apps/ios
pod install
node bundle-ui.mjs
chmod +x export-ipa.sh
./export-ipa.sh development
# IPA: apps/ios/build/ipa/TVM.ipa
```

Those scripts run:

```sh
xcodebuild -workspace TVM.xcworkspace -scheme TVM \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/TVM.xcarchive \
  archive

xcodebuild -exportArchive \
  -archivePath build/TVM.xcarchive \
  -exportPath build/ipa \
  -exportOptionsPlist ExportOptions-development.plist
```

### Unsigned / ad-hoc CI zip

GitHub Actions `mobile.yml` (macos runner) builds `apps/ui`, copies it into the
Xcode project, compiles for `iphoneos` with ad-hoc identity `-`, and zips
`TVM-unsigned.ipa`. That artifact **will not install** until you re-sign it
(Sideloadly / AltStore / Xcode). `package-unsigned-ipa.sh` is that zip step.

On Windows, after Actions has a successful `ios-ipa` run:

```powershell
cd apps\ios
.\request-ipa.ps1
# writes apps\ios\build\TVM-unsigned.ipa when the artifact exists
```

`node apps/ios/check-project.mjs` validates project references, the standalone
core, AppIcon, and the optional LAN contract. It is **not** an iOS compilation
or device test.

## Simulator compile (no signing)

```sh
cd apps/ios
node bundle-ui.mjs
xcodebuild -workspace TVM.xcworkspace -scheme TVM \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```
